# Dataset Setup

The data files are not included in this repository and must be downloaded separately.

## Download

- **ETTh1, ETTh2, ETTm1, ETTm2:** [ETT-small](https://www.kaggle.com/datasets/alaaelmor/ettsmall)
- **Weather:** [Jena weather data](https://www.bgc-jena.mpg.de/wetter/weather_data.html)
- **Electricity:** [Zenodo](https://zenodo.org/records/4656140)
- **Traffic:** [Zenodo](https://zenodo.org/records/4656132)

## File Structure

Place the CSV files in the following directories:

```text
dataset/
├── ETT-small/
│   ├── ETTh1.csv
│   ├── ETTh2.csv
│   ├── ETTm1.csv
│   └── ETTm2.csv
├── weather/
│   └── weather.csv
├── electricity/
│   └── electricity.csv
└── traffic/
    └── traffic.csv
```
